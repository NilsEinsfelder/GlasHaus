# GlasHaus 0.1

## Features (Roadmap)

- Secure customer & employee management
- Document vault with encryption
- E-Invoicing (ZUGFeRD)
- Offline-first mobile sync
- RFID + QR inventory system
- IDS Connect integration
- AI-based pricing estimator

## Architecture

- Backend: FastAPI (Python)
- Frontend: Next.js
- Mobile: React Native / Flutter
- DB: PostgreSQL
- Storage: S3/MinIO
- Auth: JWT + 2FA
